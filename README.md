# AIAA at UH Mānoa Website

Static website for the University of Hawaiʻi at Mānoa Student Branch of the American Institute of Aeronautics and Astronautics.

## Local preview

From the repository root, run:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.

The homepage is `index.html`; no build step or package installation is required.
